  • GraphQL VS REST API


  • GitHub/Front GitHub/Back


  • Fullstack projekt: I detta projekt jämfördes GraphQL och REST API:er ur ett frontendperspektiv, med fokus på datasäkerhet, autentisering och hantering av känslig information. För att möjliggöra jämförelsen byggdes en enkel bokhanteringsapplikation där båda API:erna implementerades på backend, men frontend utvecklades endast för GraphQL-versionen. Skillnader i datainhämtning, åtkomstkontroll med JWT och RBAC, cache och felhantering analyserades. Resultatet visade att GraphQL erbjuder hög flexibilitet men ökad komplexitet kring säkerhet och cache, medan REST har en tydligare struktur som förenklar säkerhetsarbetet. Slutsatsen var att frontendutvecklare, särskilt vid användning av GraphQL, behöver förstå backendarkitektur och säkerhetsprinciper. Det yttersta ansvaret för säkerheten ligger dock alltid på serversidan, vilket gör nära samarbete mellan frontend och backend avgörande.

    Säkerhetsfunktioner: JWT-token (JSON Web Token), Saltade lösenod, RBAC

    (JavaScript,HTML,CSS,React.js,Node.js,MongoDB Atlas,GraphQL API[Apollo Server], REST API[Express.js])
